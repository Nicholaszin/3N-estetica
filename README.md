# Estética Automotiva 3N

Site institucional da Estética Automotiva 3N, especializada em serviços de polimento, vitrificação, higienização e lavagem automotiva.

## 🚗 Sobre o Projeto

Este é o site oficial da Estética Automotiva 3N, desenvolvido para apresentar nossos serviços de estética automotiva de alta qualidade. O site oferece uma interface moderna e responsiva, permitindo que os clientes conheçam nossos serviços e entrem em contato facilmente através do WhatsApp.

## 💻 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Biblioteca AOS (Animate On Scroll)
- Font Awesome (ícones)

## 🌟 Funcionalidades

- Design responsivo para todos os dispositivos
- Animações suaves ao rolar a página
- Integração com WhatsApp para agendamentos
- Apresentação detalhada dos serviços
- Interface moderna e profissional
